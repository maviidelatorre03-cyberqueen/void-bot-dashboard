# Void Bot Dashboard

Dashboard oficial del bot Void, desarrollado por Nothing Studios Group.

## Características
- Panel de control con diseño responsive
- Conexión con Discord OAuth2
- Términos y Condiciones
- Política de Privacidad

## Tecnologías
- HTML5
- CSS3 (Montserrat, tema morado/negro)
- JavaScript
- Desplegado en Vercel
